# 日常流程设计（第一阶段）

> 范围只包括需求清单里的 14 项日常（商店 2、日常领取 2、笔记 5、每日活动 2、公会 3），不加别的功能。
> 规则来自用户对 Q1～Q15 的回复（2026-10-30），实测细节见 [kb/10_日常玩法实测.md](../kb/10_日常玩法实测.md)。
> 状态：✅ 脚本已实际跑通 · 🟡 部分跑通，剩余部分等游戏时间到了再验证 · ⏳ 还没写完，等可验证的时间 · ⏸ 用户要求暂时跳过。
> 坐标都是 720×1280 设备坐标。

## 1. 总流程

```
启动检查：设备在线 → 游戏没在前台就重启游戏并自动登录 → 识别当前页面
│
├─ 商店（家园 → 场景里找商人推车 → 商店）
│   ├─ 杂货 ✅  设置折扣 → 一键购买 → 刷新 → 一键购买 …… 刷新用光或到配置次数
│   └─ 宝库 ✅  买配置的商品（默认前 5 件），限购多次的买到售罄
├─ 日常领取（家园场景）
│   ├─ 糖果树 ✅  认出糖果就点；认不出就点树身，进了卡池马上退出
│   ├─ 小推车 ✅  有奖杯气泡就点一下
│   └─ 小屋 ✅  床：领经验气泡 → 今日免费加速 → 再领一次；信箱有红点就「全部领取」
├─ 笔记
│   ├─ 日常副本 ✅  选副本 → 最高可打难度 → 买 2 次 → 匹配，S 才领奖，打到次数用完
│   ├─ 羁绊冒险 ✅  领完成的委派 → 看品质 → 紫色及以上凑够 2 个就全派，不够就先锁紫再刷新（每天最多 3 次，每次 100 晨星）
│   ├─ 命运果实 ✅  地图探索里显示「可领取」才点礼物图标
│   ├─ 竞技场 ✅  买 3 张券 → 挑战最后一个对手 3 次（扫荡）
│   └─ 素材秘境 ✅  一键购买 4444，核对价格 1280 钻再买 → 黄金矿洞开采 10 次
├─ 每日活动
│   ├─ 圣兽试炼 ✅  匹配 → 接受 → 等全自动战斗打完 → 领进度奖励
│   └─ 双影幻境 ✅  同上，不开无尽模式
└─ 公会（公会 → 场景里找「远征之门」标签）
    ├─ 挂机奖励 ✅  点远征之门下方的卡片
    ├─ 捐赠 ✅  公会大厅 → 捐赠 3 次（免费、20 晨星、50 晨星）
    ├─ 公会战 ✅  周一三五 11:00～23:00，3 次，打战力 ≤ 自己 80% 的对手；9 点还没开放就推迟到 11:01
    └─ 公会讨伐 ✅  挑战 → 开始战斗 → 最小化 → 等红点再打第 2 次，次数 0 就结束
│
└─ 领取奖励 ✅（用户补充，日常都清完后）  外层入口有红点才进，分页没红点就跳过
    ├─ 精彩活动：每日签到、秘宝大作战能量（命运探索没做就先去地图探索 1 次）、赛季活动·晶芒淬炼（含积分档位）
    ├─ 主菜单·商城：每日赠礼、巡礼之证（目标经验 + 免费线等级奖励）、月卡
    ├─ 主菜单·好友：友情币
    ├─ 主菜单·馈赠：里程碑奖励
    ├─ 主菜单·任务：日常领取、委托提交
    └─ 惊魂派对 ⏳：惊奇日签、怪谈手册（刷新后实测）
│
每个任务记录结果，下次在服务器刷新（本机 09:00）后再跑；任务可以申请当天晚些时候再跑一次（公会战用）
```

## 2. 全局规则

| 项目 | 规则 | 来源 |
|---|---|---|
| 日界线 | 服务器北京时间 08:00 刷新，本机是日本时间，所以是本机 09:00。配置里是 `ServerUpdate: 08:00` + `ServerTimezone: 8`，程序换算成本机时间 | Q1 |
| 执行顺序 | 按需求清单顺序。每个任务独立，失败不影响后面的任务 | 需求 |
| 失败处理 | 卡死、连点、页面识别不了、游戏退出 → 保存最近 10 张截图 → **先试着不重启回到家园**（认不出画面时点上方空白处，见下一行），回不去或游戏已退出才**重启游戏** → 记一次失败。任务自己判断没做完（`run()` 返回 False，比如等不到讨伐打完、匹配不上）→ 保存截图、记一次失败，不重启（10-30 用户确认；之前这种情况会被记成成功）。失败后马上重试，同一任务连续失败 3 次就停下来请求人工。「今天没东西可收」（小推车、糖果树）不算失败 | Q15 |
| 资源消耗 | 用户已授权执行各项日常；**抽卡、扭蛋一律不碰**（糖果树没糖果时、商人推车左边的扭蛋机都是卡池入口） | Q2 |
| 配置 | 每项都可以在配置界面 `gui.py` 里改，见第 4 节 | Q3 |
| 认不出的弹窗（兜底） | 用户 10-31：没关掉的弹窗一般点一下四周就关，每个阶段都要有机会处理，不能只等重启。兜底点是屏幕上方中间的空白处 (360, 130)（`POPUP_OUTSIDE`），避开资源栏的付费「+」和主菜单轮播横幅；5 个主页面在这个位置都是空白（角色页是职业徽章，但角色页一定认得出，不会触发）。三个阶段：① 识别当前页面时认不出 3 秒就点一下，最多 2 次（`UI.ui_get_current_page`，每个任务开头都会走）；② 切换页面途中一直认不出，隔 3 秒点一下，最多 3 次（`UI.ui_goto`）；③ 任务出错后先识别页面回家园，回得去就不重启（`zjcs.py` 的 `recover`）。任务里自己关弹窗也改用点外面（`UI.ui_close_popup`）：返回键在弹窗动画期间会被吞掉。16:20 实测：留着公会捐赠弹窗不关，下一个任务开头 3 秒后点外面关掉、回到家园；出错恢复同样不用重启 | 用户 10-31 |
| 付费礼包弹窗 | 任何操作之后都可能弹出（10-31 见到「好感倍增礼包」6 元），点下方空白处关。脚本在每次截图时统一检查：横条里「后礼包消失」和底部「适度娱乐，理性消费。」都认出来才点 (360, 1145)，离「6元」按钮 200 像素以上；只有底部那句的商城月卡页不算（`module/device/device.py`） | 用户 10-31 |
| 点了没生效就重点 | 用户 11-01：模拟器偶尔卡两三秒，点完不能当成已经到下一步。统一用 `UI.click_until(按钮, 成功条件)`：每点一下等 3 秒看成功条件（按钮出现/消失、区域变化、页签变色、奖励弹窗），没生效就再点，最多点 3 次；还不行就抛 `GamePageUnknownError`，走「回家园 → 重启 → 连续失败 3 次找人工」。`ui_click` 也走它；`ui_goto` 加了 30 秒超时（每到一个新页面重新计时）。**会扣东西的按钮只在能证明上一下没生效时才补点**：确认框还在、数量或价格没变；状态说不清就不点。素材秘境「购买」每下等 5 秒、最多 2 下，总价不是 1280 就停。床的「今日免费加速」用掉后同一位置变成「全局加速」，认不出「今日免费加速」就停手。11-01 实测：人为吞掉第一下点击，活动入口、晶芒淬炼和巡礼之证页签、杂货页签、素材秘境「取消」、竞技场买票「取消」都补点成功；三下全吞时抛错。实跑中真的遇到了：点床第一下 2.5 秒没弹窗（第二下才开） | 用户 11-01 |

## 3. 各任务

### 3.1 商店 · 杂货 ✅

规则（Q3）：用游戏自带的「一键购买 X 折及以下」，默认 7 折；刷新次数默认用光（`-1`）。

脚本步骤（`module/shop/shop.py`）：
1. 家园场景先滑到最左端，再每次往右半屏找商人推车招牌，点车身进商店。左边约 150 像素是扭蛋机，只点招牌上方的车身。
   - 家园场景有昼夜循环（和实际时间无关），招牌有夜晚、白天两个模板。白天模板只取招牌中间「1」到右边丝带，左半常被路过的角色挡住。
   - 底部弹出「挑战赛组队邀请」（别的玩家发的）会挡住招牌：脚本等它消失，不点拒绝也不点查看（10-30 11:33 因为它找不到推车）。
2. 点齿轮 → 按折扣把滑块头拖到对应档（3 折在 x=190，每档 48.6 像素，最右是「全部」）→ 确定。
3. 一键购买（按钮显示 0 就跳过）→ 刷新（右上必须看到罗拉图标，刷新用光会变成「今日刷新已达上限」）→ 再一键购买，循环。

验证：10-30 实跑，7 折一键购买 11 批、刷新 10 次用光，罗拉 3794 万 → 3103 万。刷新价格 4000 起逐次翻倍。

10-31 改动：
- 刷新点了没反应：早上第 4 次刷新点了 4 秒次数没变就停了，只刷了 3 次。改成等 5 秒还没变就再点，最多点 3 次（再点前还要看到罗拉图标）。16:08 实测第 4 次又是第一下没反应，补点后成功，接着刷到「今日刷新已达上限」。
- 找不到推车：家园右侧有一列活动图标（精彩活动、惊魂派对……），10-31 弹过礼包后多出「限时礼包」图标，把「挑战赛」挤到 y≈450。往右滑的起点 (650, 450) 正好按在图标上，拖动被图标接走，场景不动（16:21 在最左端对比：起点 x=650 的滑法移动量 16～21，起点 x=560 或 360 的 47～56）。场景扫描改成从 (560, 330) 起手（`module/home/home.py`，糖果树、小推车也用这个扫描），小屋「滑到最右端」改成 (560, 330) → (10, 330)（`module/home/house.py`）。16:07 实测扫描 7 步每步都在动、找到推车；16:23 从最左端滑到最右端，床和信箱位置不变。

### 3.2 商店 · 宝库 ✅

规则（Q4）：买配置的商品，默认前 5 件。10-30 用户补充：「限购2次」的（例如苹果）要买满。

脚本步骤（`module/shop/shop.py` 的 `Vault`）：
1. 进商店（同杂货）→ 底部「宝库」页签。
2. 按配置的序号（只支持不用滑动的第 1～9 件）检查格子上有没有「售罄」印章；没有就点价格买一次，**点了直接买，没有确认框**（10-30 实测免费、100 钻、50 钻、30 钻都是）。
3. 同一件反复点到售罄为止，最多 3 次。点完如果离开了宝库页（例如钻石不足弹充值框），按返回键并停下，不碰弹窗。

验证：10-30 手动买了第 1～5 件（含 2 个苹果，共 260 钻）；脚本跑「全部售罄」路径通过。脚本真正购买要等明天刷新后随日常验证。

11-01：商店底部多出「特卖」页签（用户说明：特卖偶尔会出来），页签从 3 个变成 4 个，「宝库」从 x≈429 挪到 x≈360。脚本还在老位置认「宝库已选中」，页面其实已经切过去了也认不出，连续失败 4 次停机。改成在整条页签栏里按文字找「宝库」（没选中的白字、选中的黄底黑字各一个模板），3 个、4 个页签都能点对（`Vault.goto_vault_tab`）。离线核对新旧两种布局识别都对；12:12 实测买了第 1～5 件全部售罄，从杂货页切宝库点在 x=359。「杂货」的固定点击区域 [190, 290] 在两种布局里都落在杂货上，没改。

11-01 点了没生效就重点：切「杂货」页签以前点完等 1 秒就往下做，没切过去会在宝库页按「一键购买」的坐标点。改成认「杂货已选中」（黄底黑字）再往下，没选中就再点（`goto_general_tab`）；齿轮弹窗、折扣框的取消/确定也是框还在就再点。实测 `--task GeneralShop` 通过。

### 3.3 日常领取 · 糖果树 ✅

规则（Q5）：树上每隔一段时间长出一颗糖果，相当于小推车的红点。**有糖果时点第一下是收获，第二下才进卡池。**

家园场景有白天、黄昏、夜晚的循环（和真实时间无关），糖果样子随光照变化很大，模板在黄昏/夜晚只有 0.41～0.78。按用户说明（10-30）加了兜底：认不出糖果就直接点树，树上没糖果会进「幻兽结缘」卡池，进去了马上左下返回，什么都不点。

脚本步骤（`module/home/home.py`）：
1. 家园场景从左往右一步步看，每一步先按 4 张糖果素材多尺度找，相似度 > 0.7 就点糖果。
2. 认不出糖果但画面里有整棵糖果树（粉色像素 ≥ 6.5 万）：点树身粉色区域的中位点。
3. 点完等 5 秒：进了卡池就左下返回，算「没有糖果」；一直在家园就算收获了。**卡池里的「结缘」按钮绝不点。**

验证：10-30 实跑白天相似度 0.92 识别到糖果并收获；黄昏时认不出糖果，点树进卡池后立即退出，没有抽卡。

11-01 点了没生效就重点：点树身收获和没点上看起来一样（都还在家园），以前点一下等 5 秒没进卡池就记「已收获」。改成一直点到进卡池为止（每下等 5 秒，最多 3 下）：进了卡池说明树上已经没糖果（收获了或本来就没有），马上左下返回；3 下都没进卡池算失败。认出糖果时点完糖果还在就再点，离开家园就不点。13:01 实测：第一下没进卡池，第二下进了卡池并立即退出，没有抽卡。

### 3.4b 日常领取 · 小屋（床、信箱）✅（用户补充）

规则（用户 10-30 补充）：床上方有两个红点要处理：领经验、每天一次的免费加速 2 小时；信箱有红点要领信件。信箱不一定是黑猫的样子，主要看红点和位置。

脚本步骤（`module/home/house.py`）：
1. 场景快速滑到最右端（小屋位置固定）。床上方气泡区域有红色「!」就点气泡领经验（直接领，没有弹窗，可能弹升级横幅）。
2. 点床打开「床」弹窗：按钮是「今日免费加速」才点；是「全局加速」（要道具）就按返回键关掉，不点。加速后再领一次气泡。
3. 不再往右滑（床做完视角还在最右端，用户 10-31 说明），直接从最右端慢慢往回拖 450 像素，信箱区域有红点才点信箱 → 「信件」弹窗里认出「全部领取」才点；旁边的「删除已读」绝不点。
4. 点完「全部领取」，按钮会先消失，「获得奖励」横幅晚一两秒才盖到弹窗上。脚本先等横幅出现（最多 5 秒）再关掉它。
5. 信件弹窗**没有返回键**，要点弹窗外面关：点上方空白处 (360, 120)，背后是天空。没关上就隔 2 秒再点一次。

验证：10-30 手动领了两次经验（升到 308 级）、用了免费加速、领了信件（决斗币 1120、晨星 140、晶莹玉佩 1）；脚本跑「已经领过」路径通过（没有红点、加速按钮是全局加速时都正确跳过）。有红点时的脚本领取要等明天随日常验证。

10-31 随日常跑时卡在信箱：脚本领完没等「获得奖励」横幅，就按了返回键，信件弹窗一直开着，10 秒后报 GamePageUnknownError。改成先等横幅、再点弹窗外面关。10-31 当天在 5556 上验证了点外面能关（脚本 0.6 秒关掉），`--task HomeHouse` 跑通（信箱没红点）；有新信时的领取路径要等下次信箱有红点再验证。

11-01 点了没生效就重点：12:58 在 5556 上点床，第一下 2.5 秒没弹窗，第二下才弹出（真实卡顿）。改成：床没弹窗就再点；气泡点完红点还在就再点；「全局加速」时的关闭从返回键改成点弹窗外面（12:58 实测点 (360,130) 能关，截图 kb `06` 篇）；「今日免费加速」点了弹窗没关、按钮也还认得出才再点，认不出（可能已经变成全局加速）就停手点外面关。13:01 实测 `--task HomeHouse` 通过（全局加速 → 点外面关）。用免费加速和有气泡时的路径要等明天随日常验证。

### 3.4 日常领取 · 小推车 ✅

规则（Q6）：每天跑日常时点一次就行。

脚本步骤：家园场景里多尺度找黄色奖杯气泡（阈值 0.6）→ 点一下 → 等「获得奖励」弹窗出现后点屏幕顶部关闭。没有气泡就结束。

验证：10-30 实跑，领到罗拉 45.1 万和一批装备材料。

11-01 点了没生效就重点：点气泡后既没出「获得奖励」弹窗、气泡也还在，就再点。13:01 实测 `--task Cart` 领到奖励。

### 3.5 笔记 · 日常副本 ✅

规则（Q7 + 10-30 补充）：打指定副本或最新副本（进去后最新副本默认在中间），打能打的最高难度，打完所有次数。
- 额外次数默认买满 2 次（共 250 晨星），每天一共打 4 次。
- 结算 **S 评级才领奖**。评级只有 S/A/B/C/D，「极佳S」也是 S。
- 不是 S 不领（不扣次数），返回重新匹配，每次任务最多重打 3 场。

脚本步骤（`module/note/dungeon.py`）：
1. 开始时如果还在战斗、结算页或领奖确认框里（上次中断），先把这一场处理完。
2. 笔记 → 日常副本 → 点配置的副本卡片（最新 = 中间那张）。
